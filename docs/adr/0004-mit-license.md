# MIT license, contributions without a CLA

The project is released under MIT, like Playnite, which inspired it: it is the easiest license to combine with dependencies and the lowest barrier for contributors. GPL-3.0 was the alternative and was rejected because keeping forks open matters less here than easy reuse.

## Consequences

- Contributions are accepted as MIT ("inbound = outbound", stated in `CONTRIBUTING.md`); there is no CLA. Every pull request is reviewed and merged by hand, and the main branch is protected.
- CI checks dependency licenses and blocks ones that do not fit MIT, such as GPL.
- Playnite is an inspiration only. No Playnite code or assets are copied.
