# NiceLibrary

## Sprache

Dieses Projekt wird öffentlich und weicht deshalb von der globalen Regel "alles auf Deutsch" ab:

- Englisch: Code, Commit-Messages, Issues, PRs, `CONTRIBUTING.md`, `GLOSSARY.md`, ADRs.
- Zweisprachig (Deutsch und Englisch): Oberfläche und README. Jeder UI-Text läuft über das Übersetzungssystem.
- Antworten an mich im Chat bleiben Deutsch.

## Agent skills

### Issue tracker

Issues liegen in GitHub Issues von `SirKashij/NiceLibrary` (über die `gh`-CLI). See `docs/agents/issue-tracker.md`.

### Triage labels

Standard-Labels: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Implement-spec

Briefs für Orchestrator, Implementierer und Merger sowie die Hotspot-Dateien, bevor ein Spec mit parallelen Agenten umgesetzt wird. See `docs/agents/implement-spec.md`.

### Domain docs

Single-context: ein `GLOSSARY.md` und `docs/adr/` im Repo-Root. See `docs/agents/domain.md`.
