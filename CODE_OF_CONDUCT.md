# Code of conduct

NiceLibrary is a small project run in spare time. Everyone who takes part, in issues, pull requests, reviews and discussions, is expected to make it a friendly place.

## What we expect

- Be kind and patient, and assume good intent.
- Criticise ideas and code, never people.
- Accept that a maintainer may decline a contribution, and explain your own decisions when you decline one.
- Respect other people's privacy: do not post anyone's personal data, and do not ask for it.

## What we do not accept

- Harassment, insults, threats or personal attacks.
- Discriminating remarks about anyone's origin, ethnicity, sex, gender identity, sexual orientation, disability, age, religion or any other personal trait.
- Sexualised language or images.
- Publishing someone's private information without their permission.
- Spam, trolling or deliberately derailing a discussion.

## Reporting

If someone breaks this code of conduct, report it privately to the maintainers: open the [Security tab](https://github.com/SirKashij/NiceLibrary/security), choose **Report a vulnerability** and start the title with "Conduct:". Only the maintainers can read the report. You can also use GitHub's **Report content** on the comment in question, which reaches GitHub's own staff.

Reports are handled confidentially. The maintainers may edit or remove comments, close discussions, and block anyone from the project, temporarily or for good, depending on how serious the behaviour is.

## Scope

This code of conduct applies in all of the project's spaces on GitHub and wherever someone represents the project in public.

It is inspired by the [Contributor Covenant](https://www.contributor-covenant.org/), version 2.1.
